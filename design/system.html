DevBlog

Plataforma de blog técnico para desarrolladores con panel de administración.

Problema:

Necesitaba un espacio propio para publicar artículos técnicos con control total sobre el contenido, SEO y diseño.

Solución:

Plataforma completa con Next.js App Router, Prisma y PostgreSQL, con panel admin protegido con JWT.

Next.js TypeScript Prisma MDX
captura 16:9 · --muted

Task Management App

App Kanban full-stack con autenticación, drag-and-drop y gestión de tareas.

Problema:

Necesitaba una herramienta simple pero completa para gestionar tareas personales con autenticación segura.

Solución:

Tablero Kanban con Next.js 16, Better Auth, Drizzle ORM y Server Actions con control de concurrencia.

Next.js Better Auth Drizzle
