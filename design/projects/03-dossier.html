Problema

Necesitaba un espacio propio para publicar artículos técnicos con control total sobre el contenido, SEO y diseño. Las plataformas genéricas limitaban la estructura de los posts y no me permitían integrar componentes de código o diagramas con la libertad que quería.

Decisiones clave

01

Next.js App Router

Rutas estáticas para lectura pública y dinámicas para el panel admin, con metadatos por página para SEO.

02

Prisma y PostgreSQL

Modelo relacional claro para posts, categorías y tags, con migraciones versionadas y tipos generados.

03

MDX para el contenido

Artículos en Markdown con componentes React embebidos cuando el código necesita mostrarse interactivo.

04

JWT para el admin

El panel de administración está protegido con autenticación stateless, sin depender de sesiones en servidor.

Lo que entregué

  • Publicación de posts con Markdown y componentes MDX.
  • Gestión de categorías y tags desde el panel admin.
  • SEO por ruta: títulos, descripciones y rutas limpias.
  • Panel protegido donde el contenido se administra sin tocar código.

Stack y arquitectura

Frontend en Next.js con TypeScript y shadcn/ui; datos en PostgreSQL con Prisma; contenido en MDX y autenticación con JWT en el panel admin.
